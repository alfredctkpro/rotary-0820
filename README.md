## 這場在講什麼

一句話：**別人在學招式，我在練心法。**

大部分人用 AI 停在「怎麼問問題」這一層（招式）。這場分享的是底下那套配置（心法）——同一套東西，換個場景就能用。

三個真實案例，證明同一套心法可以打三個完全不同的場景：

| | 場景 | 重點在哪一層 |
|---|---|---|
| 1 | 爸媽的 LINE — 語音記行程、每天早上自動回報 | Harness |
| 2 | 全家週末旅遊 — 排出全家都能配合的行程 | Context |
| 3 | 投資決策 — AI 抓出我判準裡的錯誤 | Prompt／判準 |
