## 這支影片只證明一件事

**我下一句話，一桌立場不同的分身當著我的面吵我的錢，最後給我收斂。**

三個必須入鏡的畫面（缺一支影片就弱）：

1. **選角**——主持人點名誰上桌（依議題選角：豪瑟／馬克斯／柏格／塔雷伯這類組合）
2. **引用檔名**——席位發言時引到 `3_kb/投資心法/…`、`2_decisions/2026-08-07…`（「它讀得到我的庫」的視覺證據；引用機會成本判準＝「會累積」的證明）
3. **收斂三件套**——共識、關鍵分歧、給 Alfred 的下一步

## 🎬 流程：綵排 → 固化調味 → 正式一鏡

### 第一輪：綵排（不錄影）

輸入：

```
/roundtable --demo 台幣若走升，美元債該續抱還是設出場線？（綵排，先不落檔）
```

- 把跳出的**權限提示全部按掉**（選「此 session 不再問」）
- 檢查品質四件事：①選角合理 ②**每席都有引用檔名** ③交叉輪有點名對撞、夠嗆 ④收斂有三件套
- **金額紅線掃描**：全文掃一次，出現任何 USD／NT$ 絕對金額 → 停，回報 Alfred 修 prompt 再繼續
- 要調味就下導演指令（「馬克斯再嗆一點」「換塔雷伯上」）——調到滿意為止

### 固化調味（若綵排有調）

把有效的導演指令**寫進首場準備檔的「演出指示」段**（`6_roundtables/2026-08-12-美元債出場線-首場準備.md`）——這樣正式輪用乾淨指令也會帶入效果，**鏡頭上不會出現導演指令**。

### 第二輪：正式（開錄）

1. `/clear` 清對話 → 終端機 **Cmd+K** 清畫面
2. **QuickTime 開錄**
3. 輸入乾淨指令（這行會入鏡，就是台上說的「我只出了一句話」）：

```
/roundtable --demo 台幣若走升，美元債該續抱還是設出場線？
```

4. 全程放著跑、**不碰鍵盤**——選角 → 立場輪 → 交叉 → 收斂
5. **收斂三件套完整入鏡**（必要時捲動）→ 停止錄影

## ✂️ 剪輯規格（成品 2-2.5 分鐘）

- `--demo` 模式輸出本來就精簡（每席 ≤100 字），**幾乎全程原速**——捲動速度＝觀眾閱讀速度，這是這支影片的獨特節奏（跟 LINE 影片的快節奏對比）
- 只剪：開頭工具載入的等待空檔、席位之間如有長停頓
- **結尾停格在主持人收斂**（共識／分歧／下一步）2-3 秒

## 🎤 台上怎麼配（P32 cue 點）

1. 播放前：「來看實況。我下了這個題目——台幣若走升，三張美元債該續抱還是設出場線。看它們吵。」
2. 選角出現：「注意，不是全員都上——主持人依議題請相關的幾席。」
3. 引用檔名時（**重點 cue**）：「看，它們吵的不是理論——它們讀得到我的部位、我的決策紀錄。那條機會成本判準，是上次對話沉澱進知識庫的，**我沒有再教一次**。」
4. 收斂出現：「最後主持人收斂：共識、分歧、給我的下一步。**這場會，我只出了一句話。**」
5. 播完（萬用收束，不綁定內容）：「你看，它們提出來的這些見解，很多是我自己**從來沒想過的**。」
